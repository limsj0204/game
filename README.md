# 10초 루프

10초가 지나면 시간이 처음으로 되감기는 퍼즐 게임입니다.
방금 전의 나는 **메아리**로 남아 똑같이 다시 움직입니다. 과거의 나들과 손발을 맞춰 방을 빠져나가세요.

- 12개 스테이지 (발판, 문, 빗금 문, 상자, 메아리 여러 명)
- 스테이지마다 최소 메아리 수가 있어서, 그 수로 깨면 ★
- 효과음은 Web Audio로 직접 합성 (음원 파일 없음)
- 키보드와 터치(모바일 방향 버튼) 모두 지원
- 진행 상황은 브라우저에 자동 저장

## 실행

빌드 과정이 없습니다. `index.html`을 브라우저로 열면 바로 됩니다.

```bash
# 또는 간단한 로컬 서버로
python3 -m http.server 8000
# → http://localhost:8000
```

주소 끝에 `#unlock`을 붙이면 모든 스테이지가 열립니다(테스트용).

## 조작

| 키 | 동작 |
|---|---|
| 방향키 / WASD | 이동. 처음 움직이는 순간 시간이 흐르기 시작 |
| Space | 제자리에서 시간만 흘려보내기 |
| Enter | 지금 루프를 끝내고 메아리로 남기기 |
| R | 이번 루프만 다시 (메아리는 그대로) |
| Z | 마지막 메아리 지우기 |
| F (누르고 있기) | 3배 빨리 감기 |
| Esc / M | 스테이지 목록 / 소리 켜고 끄기 |

## 규칙

- 발판(`a b c`)을 밟고 있으면 같은 색 문(`A B C`)이 열립니다. 같은 색 발판이 여러 개면 전부 눌려야 열립니다.
- 빗금 문(`x y z`)은 반대입니다. 발판이 눌리면 닫히고 떼면 열립니다.
- 문은 누군가(또는 상자)가 걸쳐 있으면 닫히지 않습니다.
- 메아리는 녹화된 입력을 그대로 재생합니다. 그래서 길이 막히면 원래와 다르게 움직일 수 있습니다.
- 메아리는 기록이 끝난 자리에 계속 서 있습니다.
- 출구에는 지금의 나만 들어갈 수 있습니다.

## 구조

```
index.html        화면 구성
css/style.css     스타일
js/sim.js         결정론적 시뮬레이션 (브라우저 + Node 공용)
js/levels.js      스테이지 데이터와 검증용 풀이
js/render.js      캔버스 그리기
js/audio.js       효과음 합성
js/game.js        루프 진행, 입력, 화면 전환
tests/verify.js   스테이지 검증
```

게임 로직은 60틱/초 고정 간격으로 돌아가고, 같은 입력이면 항상 같은 결과가 나옵니다.
메아리는 플레이어의 틱별 입력 기록을 그대로 다시 넣어서 재생합니다.

## 스테이지 검증

```bash
npm test   # = node tests/verify.js
```

- 모든 스테이지의 풀이(`levels.js`의 `solution`)를 실제 시뮬레이션으로 돌려 탈출하는지 확인합니다.
- 메아리가 필요한 스테이지가 메아리 없이 풀리지 않는지 탐색으로 확인합니다.
- 발판이 자기 문 바로 옆에 붙어 있어 혼자 통과되는 실수가 없는지 확인합니다.

### 스테이지 추가하기

`js/levels.js`에 맵을 문자열로 그리고 풀이를 적은 뒤 `npm test`로 확인하세요.

```
#  벽        .  바닥       S  시작      E  출구      o  상자
a b c  발판   A B C  문     x y z  빗금 문
```

풀이는 루프마다 한 줄씩 `U D L R`(+칸 수), `w`(+틱 수, 60틱 = 1초), `X`(루프 끝내기)로 적습니다.
